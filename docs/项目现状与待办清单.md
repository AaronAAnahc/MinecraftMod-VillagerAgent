# 当前实现边界与验证状态

核对日期：2026-10-23。本文列出源码可确认的范围与限制；实际开发任务由用户指定。各专题是当前机制的说明入口。

| 主题 | 当前实现范围 | 限制或待核验点 |
|---|---|---|
| 主循环 | 慢感知、Utility 抽样、逐 tick 技能、统一退出 | 游戏内连续执行和异常场景需要实测 |
| 资源工作 | 伐木/采矿角色、订单租约、部分交付、库存核对 | 局部暴露资源；地下掘进、整树、高处脚手架、跨区域探索无完整任务方法 |
| 目标生命周期 | 冷却、等待、最多三次失败退出、routine 延迟重建 | 检查来源资格与 handler 的对应关系 |
| 空间感知 | 区块摘要、床锚点建筑、视锥近景 | 预算盒截断、窄洞合并、薄装饰阻挡、墙后遮挡 |
| 建筑索引 | 床/区块播种，事件失效，每维度保存 | 未加载床出队等待再 offer；命令生成床的发现覆盖需要验收 |

## 验证状态

本次文档整理核对了工作区源码、配置与调用点；未执行 Java 构建、游戏启动或场景测试。当前自动检查入口与手工验收方法见 [调试手册](DEBUG_VERIFICATION.md)。仓库内日志或模拟脚本需要确认生成它们的版本和条件，才能用于当前实现的验证。

## 扩展时保持的接口约束

新增目标需要生产者、可执行类型映射、资格检查、技能方法、完成证据和退出清理。多步技能的每村民状态挂在 agent/动作对象上；声明持久化时核对实际 NBT 字段。物品转移核对实际容纳数量，异步世界写入回服务端线程重查条件。扩展资源目录时同时定义产物、来源方块、工具和承接资格。
